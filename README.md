# Spotify Insights

Spotify Insights is a personal analytics dashboard built using the Spotify Web API.

The application will retrieve personal listening data, store periodic snapshots and display custom statistics about listening habits.

## Planned features

- Spotify OAuth 2.0 authentication
- Top artists and tracks
- Listening history snapshots
- Monthly listening comparisons
- Obscurity Score
- Interactive charts
- Automated background data collection

## Tech stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- JavaScript
- Chart.js
